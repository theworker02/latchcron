# latchcron

Latch filesystem cron paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/latchcron/

## Install / run

```bash
git clone https://github.com/theworker02/latchcron.git
cd latchcron
node src/cli.js
node --test
```
